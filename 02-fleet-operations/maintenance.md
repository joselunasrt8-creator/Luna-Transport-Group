# Maintenance Management

## Asset register
Unit ID, VIN, plate, year/make/model, ownership/lease, mileage/engine hours, warranty, inspection dates, PM intervals, tire details, repair history, open defects, downtime, vendor, documents.

## Preventive maintenance
Set schedules using manufacturer requirements, applicable rules, duty cycle, mileage/hours, and qualified advice. Record due/completed date and mileage, work order, parts/labor, vendor, inspection, and next due point.

## Defect workflow
Report → classify safety/operability → restrict/remove from service when required → assign qualified repair → verify completion → authorize return to service → close record. Dispatch cannot override a safety-related restriction.

## Breakdown
Protect people and scene; secure cargo; notify dispatch/customer; arrange authorized repair/tow; document location, time, cause if known, cost, delay, and return-to-service verification.

## Measures
PM compliance, road calls per mile, maintenance cost per mile, downtime, repeat repairs, tire cost per mile, open safety-critical defects, vendor turnaround.
