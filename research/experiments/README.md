# Experiments

One folder per experiment. Include protocol, baseline reference, execution log, analysis, and decision.

## Protocol
ID/title/owner; question; hypothesis and alternatives; scope/population/dates; inclusion/exclusion; baseline/comparison; intervention/version; primary/secondary metrics and formulas; sources/collection; risks and stop conditions; analysis plan; limitations; approval/freeze date.

Never compromise safety, compliance, customer commitments, or employee protections to run an experiment.
