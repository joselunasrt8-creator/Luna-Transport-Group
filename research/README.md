# Research

This directory holds controlled experiments, datasets, and findings used to improve operations.

Lifecycle: question → protocol → baseline → bounded intervention → measurement → analysis → finding → authorized decision → versioned SOP → follow-up.

Record scope, population, period, definitions, sources, transformations, limitations, and owner. Preserve unfavorable/null outcomes. Do not infer causation from uncontrolled before/after comparisons. Protect personal, customer, and financial information; use approved de-identified data.

Folders: experiments (protocol/execution), datasets (schemas/dictionaries/approved extracts), findings (dated analysis and decisions). A finding may recommend change; only designated company authority approves policy.
