# Findings

Each finding is a dated, reviewable record.

## Template
ID/title/owner/date/status; question/scope; evidence and dataset IDs; method/metric definitions; results including nulls; limitations/alternative explanations; operational implication; proposed SOP change; decision authority/date; implementation owner/review date; follow-up outcome.

Statuses: draft, reviewed, accepted for bounded trial, adopted, rejected, superseded. Adoption requires explicit company decision and versioned SOP update.
