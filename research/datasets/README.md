# Datasets

Store schemas, dictionaries, provenance notes, and approved de-identified extracts. Never commit credentials, personal driver records, medical/qualification documents, confidential rate sheets, bank details, or restricted records.

## Manifest
Dataset ID/purpose/owner; sources; period/extraction time; schema version; row count; units; missingness; transformations/exclusions; de-identification; access class; retention; checksum; limitations.

Check IDs, duplicates, timestamps/time zones, mileage units, currency, nulls, impossible values, reconciliation, and source traceability. Preserve raw records; append corrections with reason, actor, time, and superseded value.
